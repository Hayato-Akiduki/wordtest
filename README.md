# 単語テスト

単語テスト用サイト

ブラウザで index.html を開き、「ファイルを追加」から XLSX を選びます。ホームの単語帳一覧で「テスト開始」を選ぶと学習できます。

## キーボードで学習する

- Tab／Shift＋Tab で操作する項目を選び、Enter でボタンを押します。
- フラッシュカードでは、学習画面に入ったら Space でカードをめくり、←で不正解、→で正解、↓でスキップできます。
- クイズとタイムアタックでは、学習画面に入ったら数字キー 1〜4 で回答できます。
- 綴り入力では Enter で答え合わせをします。不正解のあと、Enter で同じ単語に再挑戦し、Shift＋Enter で次の問題に進めます。

## 中断して再開する

学習中に「中断して保存」を押します。Ctrl／⌘＋Shift＋S でも保存できます。再開するときは、同じブラウザで単語帳を開き、「前回の続きから再開」を選びます。

単語帳ごとに最新の保存1件をブラウザに保持します。問題順、回答数、カードの表裏や綴り入力の書きかけを復元します。タイムアタックは、再開した問題の制限時間を最初から数えます。
